# 魔法世界文字 MUD UI 规范

> 版本：0.1
> 视觉方向：暗色学院档案
> 目标平台：桌面网页优先
> 基线视口：1440 × 900，最低桌面宽度 1024px

## 1. 设计原则

### 1.1 叙事优先

- 正文与自由输入始终是页面唯一主任务。
- 地图、人物、线索、状态和物品提供上下文，不与正文争夺视觉焦点。
- 氛围装饰不得降低阅读清晰度，不在正文背后放高对比纹样。

### 1.2 高密度但有层级

- 使用紧凑间距和小字号承载游戏状态。
- 依靠明度、阴影、材质、字重和局部金色建立层级，不依靠密集分割线。
- 主操作始终首屏可见。
- 页面不整体滚动，各内容区独立滚动。

### 1.3 规则可追溯

- 判定、关系变化、世界记忆和状态写入在对话流中留下记录。
- 玩家能展开查看公开依据，但看不到隐藏 DC、暗骰和 NPC 秘密。
- AI 生成内容与权威状态在视觉上有明确区别。

### 1.4 魔法感来自工艺，不来自堆特效

- 核心质感：黑胡桃木、旧黄铜、深色墨水、羊皮纸、压印档案标签。
- 主要装饰：切角、双线边框、细金线、菱形铆钉、微弱纸张噪点。
- 魔法光效只用于掷骰、重要状态改变和罕见天赋，不常驻发光。

## 2. 页面结构

### 2.1 桌面三栏

| 区域 | 1440px 基线 | 最小值 | 用途 |
|---|---:|---:|---|
| 场景栏 | 216px | 196px | 小地图、在场人物、近期日程、场景风险 |
| 叙事区 | 自适应 | 620px | 对话流、判定卡、自由输入 |
| 检查器 | 276px | 250px | 人物、线索、状态、物品及上下文详情 |

- 删除独立全局导航轨。
- 低频入口放在顶部世界状态栏。
- 场景栏和检查器均可折叠。
- 1024–1080px 下，场景栏默认收起，以覆盖式抽屉打开。

### 2.2 固定区域

- 顶部唯一状态栏：54px。
- 不设置第二条叙事工具栏；章节名、时间和低频菜单合并到顶栏。
- 输入坞：初始约 138px，可随多段输入扩展，但最大不超过 220px。
- 检查器标签栏：46px。
- 弹窗标题区：56–64px。
- 弹窗操作区：52–60px。

### 2.3 滚动

- `body` 禁止滚动。
- 场景栏内容、叙事流、检查器内容分别滚动。
- 输入框、标签栏和弹窗操作区固定。
- 新消息到达时，仅当玩家已接近底部才自动滚到底。
- 玩家回看历史时显示“回到最新”按钮，不强制拉回。

## 3. 尺寸与间距

采用 4px 基础网格。

| Token | 值 | 用途 |
|---|---:|---|
| `space-1` | 4px | 图标与文字、紧凑标签 |
| `space-2` | 8px | 卡片内部小间距 |
| `space-3` | 12px | 标准控件间距 |
| `space-4` | 16px | 面板内边距 |
| `space-5` | 20px | 模块间距 |
| `space-6` | 24px | 弹窗与大卡片内边距 |

禁止在高频游玩界面使用超过 32px 的纯留白。

### 圆角

- 小控件：8–9px。
- 输入框与普通卡片：10–12px。
- 主面板：16px。
- 弹窗：12px。
- 头像：圆形。
- 主题卡片可使用 6px 切角替代圆角。

## 4. 字体

### 4.1 字体角色

- UI：系统无衬线字体，保证中文小字号清晰。
- 叙事正文：可读性高的宋体或现代衬线体。
- 数值与时间：等宽数字特性，避免状态跳动。
- 标题不使用仿电影 Logo 字体，避免版权风险与低可读性。

### 4.2 字号

| 层级 | 字号 / 行高 | 用途 |
|---|---|---|
| `caption` | 9px / 13px | 标签、时间、辅助说明 |
| `meta` | 10px / 14px | 状态、关系描述、修正项 |
| `ui-small` | 11px / 16px | 按钮、列表标题 |
| `ui` | 12px / 18px | 常规 UI 文本 |
| `body` | 14px / 24px | 叙事正文 |
| `body-large` | 15px / 26px | 专注阅读模式 |
| `title` | 16px / 22px | 面板和弹窗标题 |
| `display` | 20px / 28px | 重大结果与章节标题 |

正文单行建议 36–48 个中文字符，最大宽度约 720px。

## 5. 色彩

### 5.1 中性背景

| Token | 色值 | 用途 |
|---|---|---|
| `ink-950` | `#0B0D10` | 页面最深背景 |
| `ink-900` | `#111419` | 叙事区 |
| `ink-850` | `#161A20` | 面板背景 |
| `ink-800` | `#1D222A` | 卡片与悬浮层 |
| `ink-700` | `#292F39` | 选中与次级表面 |
| `line` | `#3A414D` | 普通边框 |
| `line-strong` | `#565F6D` | 重点边框 |

### 5.2 文字

| Token | 色值 | 用途 |
|---|---|---|
| `text-1` | `#F1EEE6` | 主文字 |
| `text-2` | `#C3C1BA` | 次文字 |
| `text-3` | `#858A92` | 辅助文字 |
| `text-disabled` | `#5E646D` | 禁用 |

### 5.3 暗金

| Token | 色值 | 用途 |
|---|---|---|
| `brass-300` | `#E1C477` | 高亮与重要数字 |
| `brass-400` | `#C7A65B` | 主按钮与选中线 |
| `brass-600` | `#806735` | 深色边框与压印 |
| `brass-surface` | `#2B261A` | 金色弱背景 |

金色面积不得超过当前视口的 8%，避免廉价和刺眼。

### 5.4 语义色

- 成功：`#7FB393`。
- 警告：`#D1A662`。
- 危险：`#C97979`。
- 信息：`#7D9EBB`。
- 神秘：`#9B87B9`。

语义不能只靠颜色表达，必须配合文字或形状。

## 6. 表面与装饰

### 6.1 面板

- 三个主工作面以 9–12px 间距悬浮于背景材质上。
- 常规区域不使用连续 1px 分割线，以表面明度和阴影区分层级。
- 左右栏内部模块使用低对比悬浮卡片，模块之间保留背景呼吸区。
- 主叙事面板使用最深阴影；正文卡、判定卡和输入坞按交互优先级逐级抬高。
- 只有输入焦点、判定风险和重要状态使用金色描边。

### 6.2 羊皮纸

- 仅用于信件、人物档案原件、课程通知和世界事实文档。
- 不用于长时间主叙事背景。
- 羊皮纸卡片正文使用深墨色文字，保证对比度。

### 6.3 纹理

- 背景纹理透明度 2–5%。
- 不在小字号文字背后放纹理。
- 首选 CSS 噪点、渐变和细线；位图仅用于场景氛围图或特殊档案封面。

## 7. 图标

### 7.1 功能图标

- 统一视觉盒：16×16px 或 20×20px。
- 线宽约 1.5px。
- 正常态使用 `text-3`，悬浮使用 `text-1`，选中使用 `brass-300`。
- 不使用填满背景的彩色 App 图标。
- 所有图标必须有文本 Tooltip 和无障碍名称。

### 7.2 定制图标

适合定制的主题图标：

- 魔杖。
- 羊皮卷。
- 蜡封。
- 记忆瓶。
- D20。
- 活点地图折页。
- 学院档案夹。

输出要求：

- 透明背景 PNG。
- 原图至少 512×512。
- 主体位于中央 70% 区域。
- 外轮廓清晰，无绿色或白色毛边。
- 缩小到 20px 后仍可识别。
- 去背后输出 `1x/2x` WebP 和 PNG 回退。

## 8. 核心组件

### 8.1 顶部世界状态栏

- 左：当前地点、自动保存状态和窄屏场景栏入口。
- 中：章节名、日期时间和场景状态。
- 右：专注模式、低频“更多”菜单和人物卡。
- AI 配置、时间线与本轮记录收进低频菜单。
- 不增加汉堡菜单或一级导航。

### 8.2 场景栏

顺序固定：

1. 小地图。
2. 在场人物。
3. 接下来日程。
4. 场景风险。

在场人物行高 42–46px，头像 30px。最多直接显示 5 人，更多折叠。

### 8.3 对话流

- 短回复沿用气泡式呈现。
- 长篇 AI 输出采用“单次角色回合文稿”，头像、人物名和回合操作只出现一次。
- 同一回合中的动作、台词、内心与场景反应保持连续段落，不拆成多条伪聊天消息。
- 长回合正文采用衬线体、限制阅读宽度，并保留原始段落。
- 可选语义增强包括台词段、内心停顿和场景节拍；没有结构化标记时必须退化为正常正文，不能依赖脆弱的引号正则。
- 长回合头部在正文滚动期间可粘滞，底部提供字数、阅读时间、编辑、重试和状态变化入口。
- 系统状态：使用窄条记录，不伪装成角色发言。
- 同一 NPC 连续短发言可合并，减少头像重复。

### 8.4 输入区

- 默认模式是“混合叙事”，不要求玩家在行动、对话、施法或观察之间互斥选择。
- 一次回合允许输入多个段落，同时包含动作、直接台词、内心思考和施法。
- 提供“插入表达”菜单，帮助插入台词、动作和内心模板，但模板不是协议要求。
- 输入框初始显示 3–4 行，并随内容自动增高。
- 主操作区包含两个完整按钮：
  - `主动判定`：玩家明确要求规则层对当前描述进行裁定。
  - `提交回合`：提交完整表达，由系统自动判断是否需要判定。
- 主动判定必须包含 D20 图标、动作名称和说明文字，不能作为输入框角落里的文本链接。
- `Enter` 正常换行，`Ctrl/⌘ + Enter` 提交完整回合。

### 8.5 判定卡

待确认：

- 行动目标。
- 属性与技能。
- 可见修正。
- 风险。
- 修改行动、重新裁定、确认掷骰。

已完成：

- 骰面。
- 总值。
- 结果等级。
- 直接后果。
- 展开公开依据。

结果卡留在消息流中，不只显示 Toast。

### 8.6 3D 骰盘

- 重要判定覆盖主工作区。
- 顶部世界时间仍可见。
- 骰子落定后保留至少 800ms。
- 提供跳过动画和减少动态效果。
- 权威点数由规则引擎提供，动画只表现结果。

### 8.7 检查器

标签固定：人物、线索、状态、物品。

- 同一时间只显示一个工具。
- 点击地图、记忆或判定依据时可临时替换内容。
- 返回标签时恢复上次浏览位置。
- 精确关系值仅在调试模式出现。

### 8.8 弹窗

- 标题区和底部操作区固定。
- 内容区独立滚动。
- 主按钮放右侧。
- 不允许弹窗套弹窗。
- 高端 AI 演算可使用阻断式弹窗；普通加载不能阻断页面。

## 9. 动效

| 动效 | 时长 | 曲线 |
|---|---:|---|
| 悬浮反馈 | 100–140ms | ease-out |
| 侧栏切换 | 160–220ms | ease-out |
| 抽屉打开 | 200–260ms | cubic-bezier(.2,.8,.2,1) |
| 判定卡出现 | 180ms | ease-out |
| 普通状态变化 | 240ms | ease-in-out |

- 页面不使用持续漂浮粒子。
- 金色辉光最多持续 800ms。
- 尊重 `prefers-reduced-motion`。

## 10. 可访问性

- 正文与背景对比度至少 4.5:1。
- 键盘可以完成发送、切换标签、打开/关闭弹窗和掷骰。
- 焦点环使用 2px 暗金色，不仅依靠阴影。
- 3D 骰子必须同时给出文本结果。
- 状态轨同时显示数字。
- 头像首字母不是唯一身份信息，旁边必须有姓名。

## 11. 素材生成与处理

### 11.1 Crate 生成流程

```bash
bytedcli --site i18n-tt auth login

CRATE_TOKEN="$(
  bytedcli --json --site i18n-tt \
    auth get-bytecloud-jwt-token |
  jq -r '.data.jwt'
)" crate generate image \
  --model gpt-image-1.5 \
  --prompt "<prompt>" \
  --width 1536 \
  --height 1024 \
  --params '{"quality":"high"}' \
  --output "<absolute-output-path>" \
  --json
```

Token 只注入单条进程，不写入仓库、脚本或日志。

### 11.2 背景图提示词要求

- 明确“dark academic magical archive”。
- 只生成低对比材质，不生成可识别影视场景。
- 不使用演员肖像、官方纹章、电影 Logo 或官方游戏资产。
- 预留大面积安静区域供文字覆盖。
- 指定无文字、无水印、无边框。

### 11.3 去背检查

1. 检查四角是否真正透明。
2. 检查主体边缘是否有白边、绿边或半透明杂色。
3. 在黑、白、金三种底色上预览。
4. 裁剪透明空白，但保留 4–8% 安全边距。
5. 输出 PNG 与 WebP。
6. 记录原始 Prompt、模型和生成日期。

## 12. 首轮换皮边界

首轮只换：

- 全局色彩与字体。
- 面板边框、切角和暗金装饰。
- 消息、记忆条、判定卡和弹窗。
- 输入框与按钮。
- 小地图与状态轨。
- 一张低对比档案背景纹理。
- D20、魔杖、记忆、地图四个主题图标。

首轮不换：

- NPC 角色立绘。
- 学院官方纹章。
- 影视场景截图。
- 复杂粒子和全屏魔法特效。
